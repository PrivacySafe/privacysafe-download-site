# Security

This repository contains the source for `download.privacysafe.app`.

Report security or privacy vulnerabilities confidentially to:

`security@privacysafe.net`

GPG fingerprint:

`7E3E C7D6 D965 CF1D 8C76 8F80 74AB DBE3 E3FB C689`

Canonical security policy:

https://ivycyber.com/security-policy/

Canonical security.txt:

https://privacysafe.app/security.txt

Do not send passwords, recovery phrases, private keys, full payment credentials,
or other secrets through ordinary email. If sensitive material is necessary,
encrypt it to the published security key first.
